# Contributing

This repository is a community-maintained continuation of the original project.

1. Create a focused branch from `main`.
2. Include an upgrade note when a change affects configuration or the database.
3. Run the PHP lint and the security test before opening a pull request.
4. Do not commit `config.php`, cloud-storage credentials, API tokens, uploaded files, or production database exports.
5. Preserve the upstream MIT license and attribution in redistributed copies.

Use semantic release tags: patch releases for fixes, minor releases for compatible features, and major releases for breaking changes.
